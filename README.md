# Probabilistic-River-Level-Forecasting-with-LSTM-and-APU-
Focused on the Sinos River Basin (RS), this study presents a model for 2 to 48-hour river level forecasting using only stage data. Combining LSTM, Analytical Propagation of Uncertainty (APU), and hysteresis rules, the method generates calibrated forecasts and reliable confidence intervals, reducing false alarms in extreme floods.
